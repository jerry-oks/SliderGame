# SliderGame
Игра, в которой нужно положением слайдера указать загаданное число.
Имеет 5 уровней сложности и чит-моуд.

## Стэк
+ Xcode
+ Swift
+ SwiftUI

## Цели и задачи
+ использование представлений UIKit в SwiftUI с помощью UIViewRepresentation
+ изучение элементов интерфейса SwiftUI
+ разделение приложения на слои (модельный, сервисный и представления)
